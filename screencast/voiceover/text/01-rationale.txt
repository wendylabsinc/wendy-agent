This is the core rationale for top-level files in wendy.json. A lot of edge applications have inputs that are part of the deployment, but not really part of the image: prompts, model sidecars, calibration tables, test fixtures, and configuration snapshots. Before this change, the practical options were to bake those files into the image or invent an ad hoc transfer step. The new files block makes them explicit deployment inputs for wendy run.
