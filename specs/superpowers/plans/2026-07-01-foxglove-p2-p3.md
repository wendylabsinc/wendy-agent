# Foxglove P2/P3 + efficient read path — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend `wendy device foxglove serve` from read-only into a full Foxglove Studio bridge (ROS 2 parameters, service calls, publishing) while making the subscribe path efficient for huge datasets (images, point clouds, lidar).

**Architecture:** The subscribe hot path is replaced by an inline rclpy raw-subscription forwarder in the sidecar that emits length-framed binary CDR (no text blowup, no device-side decode) — pure passthrough to Foxglove. The low-rate write path (publish, service calls) uses a new Go CDR codec to bridge Foxglove's CDR ⇆ the `ros2` CLI's YAML. Parameters map JSON ⇄ `ros2 param` YAML with no codec. Writing is opt-in behind `--allow-control`.

**Tech Stack:** Go 1.26, gRPC, Cobra, `github.com/coder/websocket`, ROS 2 `ros2` CLI + rclpy (in the sidecar), Foxglove WebSocket Protocol v1.

## Global Constraints

- Module `github.com/wendylabsinc/wendy`; all Go under `go/`; tests run `go test ./go/...` from repo root. Go floor `go 1.26.4`.
- New agent RPCs go in `Proto/wendy/agent/services/v2/ros2_service.proto` (package `wendy.agent.services.v2`); regenerate with `bash go/scripts/generate-proto.sh`; commit generated `go/proto/gen/agentpb/v2/*`. Import alias `agentpbv2`.
- Reuse existing ROS 2 patterns: `s.resolveSidecars`, `s.pickSidecarForTopic`/`pickSidecarForService`/`pickSidecarForNode`, `s.runIn`, `s.runtime.ExecROS2`, `validateROS2GraphName`, `validateROS2ParamName`. The sidecar exec runs a single binary with args passed via `"$@"` (no shell interpretation) — never introduce shell metacharacters.
- WebSocket server binds `127.0.0.1` by default. Subscribe channels stay `encoding=cdr`, `schemaEncoding=ros2msg`. `supportedEncodings=["cdr"]` for the write path.
- Foxglove opcodes: server→client MESSAGE_DATA `0x01`, SERVICE_CALL_RESPONSE `0x03`; client→server CLIENT_MESSAGE_DATA `0x01`, SERVICE_CALL_REQUEST `0x02`. Capability strings: `"clientPublish"`, `"parameters"`, `"parametersSubscribe"`, `"services"`.
- Agent handlers return `status.Errorf(codes.…, …)`; CLI maps transport errors via `ros2RPCError`. Per-topic/service/stream isolation — one failure never kills the connection.
- Write path (publish, service calls, `setParameters`) is gated behind `--allow-control`; default is read-only.

```go
package services

import (
	"encoding/binary"
	"fmt"
	"io"
)

// ros2ForwarderScript returns a self-contained rclpy program (run via
// `python3 -c`) that raw-subscribes one topic and writes each message to stdout
// as a length-framed binary CDR record: [uint32 LE length][raw CDR bytes]. This
// avoids the ~4x text inflation and per-byte decode of `ros2 topic echo --raw`.
// The topic is passed as argv[1] (via ExecROS2 "$@"), never interpolated, so the
// script contains no untrusted input. Uses best-effort, KEEP_LAST depth-1 QoS to
// match sensor publishers and favour the freshest sample.
func ros2ForwarderScript() string {
	return `
import sys, struct
import rclpy
from rclpy.node import Node
from rclpy.qos import QoSProfile, ReliabilityPolicy, HistoryPolicy
from rosidl_runtime_py.utilities import get_message
from ros2topic.api import get_msg_class

topic = sys.argv[1]
rclpy.init(args=None)
node = Node('wendy_foxglove_forward')
# Resolve the message type from the live graph (waits briefly for a publisher).
msg_cls = get_msg_class(node, topic, blocking=True, include_hidden_topics=True)
qos = QoSProfile(depth=1, reliability=ReliabilityPolicy.BEST_EFFORT, history=HistoryPolicy.KEEP_LAST)
out = sys.stdout.buffer
def cb(raw):
    # raw is a serialized (CDR) message because the subscription is raw=True.
    out.write(struct.pack('<I', len(raw)))
    out.write(raw)
    out.flush()
node.create_subscription(msg_cls, topic, cb, qos, raw=True)
rclpy.spin(node)
`
}

// readCDRFrames reads [uint32 LE length][payload] frames from r and calls emit
// for each. emit must copy any bytes it needs to retain; the slice is reused.
// Returns nil on clean EOF, an error on a truncated frame or emit failure.
func readCDRFrames(r io.Reader, emit func(cdr []byte) error) error {
	var hdr [4]byte
	buf := make([]byte, 0, 1<<20)
	for {
		if _, err := io.ReadFull(r, hdr[:]); err != nil {
			if err == io.EOF {
				return nil
			}
			if err == io.ErrUnexpectedEOF {
				return fmt.Errorf("truncated frame header")
			}
			return err
		}
		n := binary.LittleEndian.Uint32(hdr[:])
		if uint32(cap(buf)) < n {
			buf = make([]byte, n)
		}
		buf = buf[:n]
		if _, err := io.ReadFull(r, buf); err != nil {
			return fmt.Errorf("truncated frame payload (%d bytes): %w", n, err)
		}
		if err := emit(buf); err != nil {
			return err
		}
	}
}
```

```go
// fgAppendMessageData appends a binary MESSAGE_DATA frame to dst and returns the
// grown slice: [opcode 0x01][subscriptionId u32 LE][timestamp u64 LE][payload].
func fgAppendMessageData(dst []byte, subID uint32, timestampNs uint64, payload []byte) []byte {
	var hdr [13]byte
	hdr[0] = 0x01
	binary.LittleEndian.PutUint32(hdr[1:5], subID)
	binary.LittleEndian.PutUint64(hdr[5:13], timestampNs)
	dst = append(dst, hdr[:]...)
	return append(dst, payload...)
}

func fgEncodeMessageData(subID uint32, timestampNs uint64, payload []byte) []byte {
	return fgAppendMessageData(make([]byte, 0, 13+len(payload)), subID, timestampNs, payload)
}
```
