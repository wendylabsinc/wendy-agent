# General Coordinator Handover

Read `PLAN.md` first. This worktree is for coordinator planning only; do not
implement issue work here.

Use this coordinator for top-level Wendy Agent issues that do not belong to a
more specific coordinator worktree. When starting an issue, follow the protocol
in `PLAN.md`: assign Linear, create a dedicated worktree/branch, add an empty
setup commit, push, open a draft PR with a body file, and write that issue
worktree's `HANDOVER.md`.

Current issue lists are intentionally `TBD`; fill them in during the coordinator
session.
