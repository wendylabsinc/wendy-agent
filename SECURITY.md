# Security Policy

## Supported Versions

WendyOS offers a stable API, but requires the latest OS and tools installed for security updates.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in WendyOS please do not post this in a public forum, do not create a GitHub Issue. Instead you should submit a security advisory via [GitHub](https://github.com/wendylabsinc/wendyos/security/advisories/new) with details of the issue.

To see how we respond to a security vulnerability report you can read our [incident_response.md](https://github.com/wendylabsinc/wendyos/tree/main/docs/incident_response.md) document.
